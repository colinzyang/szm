## 投稿上墙 Submit（自动通道）

```
第 1 步  打开「投稿模板」，填标题、贴图、写介绍
第 2 步  等馆长给 Issue 打上「上架」标签
第 3 步  机器人收图 → 挂画 → 网站自动更新，Issue 自动关闭
```

- 支持格式：`jpg / png / webp / gif`，单张 ≤ 15MB（大图会自动压缩）
- 你的 GitHub ID 会刻在展签上，永久署名
- 不想用 Issue？[PR 直投通道](CONTRIBUTING.md) 也永远开放

## 论坛公约 Forum Rules

- **不改别人的楼**：只在自己的楼层编辑，管理员除外
- **图片要有版权**：只投自己拍 / 自己画 / 已获授权的作品
- **友善冲浪**：可以整活，不可伤人；馆长保留删楼权（会注明原因）

## 线上美术馆 The Gallery

博物馆级体验，零依赖纯静态：

- 博物馆展框 · 3D 倾斜 + 聚光灯跟随
- 全屏鉴赏 · 键盘 `←→` 切换 / `Esc` 关闭 / 单击放大
- 电影感开屏 + Ken Burns 英雄区 + 跑马灯
- 实时馆务数据（馆藏数 / 策展人数随社区生长）
- 点 Star 放烟花 · 隐藏彩蛋 `↑↑↓↓←→←→BA`
- 键盘可达 · `prefers-reduced-motion` 友好

本地鉴赏：直接打开 `index.html`，或 `python3 -m http.server 8000`
